Introduction
===============

DisplayLink Direct is a developer toolkit that provides C/C++ APIs,
libraries, and headers for presenting pixel buffers across multiple DisplayLink displays.

Documentation is available at:
https://displaylink.github.io/displaylink-direct


Changelog
==============================

Changes in the 2.0.0+g287e926058.build4 release
-------------------------------------------
- First public release
- Improve inline documentation
- Add thread-safety support
- Add HDR API support
- Add APIs to enable and disable virtual HPD polling on the DP AUX interface
- Add display brightness API
- Make dlsdk_initialise and dlsdk_display_clear return status codes
- Improve the frame presentation API
- Improve the dlsdk_display_power_on API
- Rename dlsdk_update_firmware to dlsdk_device_update_firmware
- Rename the AuxStatus enum to dlsdk_aux_status_t
- Rename dlsdk_restart_and_free_device to dlsdk_restart_device
- Remove dlsdk_free_device

Changes in the 1.5.3.post4+gc7e3611c2c3.build4 release
-------------------------------------------

Changes in the 1.5.2.post3+ga39ced7b244.build8 release

  dlsdk_dpaux_disable_virtual_hpd_polling functions (SYNAP-4)

Changes in the 1.5.1.post12+g873f87913e4.build11 release
