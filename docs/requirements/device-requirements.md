# DisplayLink Device Requirements

DisplayLink Direct supports DisplayLink-enabled devices that are available on
the market. A representative set of products can be found on the Synaptics
[DisplayLink products list](https://www.synaptics.com/products/displaylink-graphics/displaylink-products-list?field_displaylink_category_value=universal_docking_stations).

## Supported device categories

DisplayLink Direct can be used with DisplayLink devices across common product
categories, including:

- PCIe 3.0 expansion cards.
- USB monitors.
- USB adapters.
- Docking stations.

## Choosing a device

- Confirm that the product uses DisplayLink technology.
- Choose a device with display outputs and maximum resolutions that match your
	target deployment.
- For higher resolutions, multiple displays, or video-heavy workloads, prefer
	devices paired with USB 3.2 Gen 1 or better host connectivity.

## Notes

- Supported host-side operating systems and architectures for this SDK release
	are listed in the Supported Platforms section.
- Actual display capabilities depend on the specific DisplayLink device,
	connected displays, host performance, and available USB bandwidth.
- Device capabilities may be constrained when embedded mode is selected. See
	Embedded Mode for details on behavior and limits.
