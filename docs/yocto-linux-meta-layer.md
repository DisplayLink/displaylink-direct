# Yocto Linux Meta-Layer

Yocto Project, available at [yoctoproject.org](https://www.yoctoproject.org/), is a build system used to create custom Linux distributions for embedded devices. It is commonly used when you need a controlled, reproducible image with only the components required for a specific product.

The DisplayLink Direct Yocto meta-layer will provide recipes and integration pieces for building Yocto-based systems that use DisplayLink Direct. It is intended to make it easier to bring up embedded platforms that need display output over DisplayLink hardware.

Planned content for the meta-layer includes:

- Core libraries needed to build and run DisplayLink Direct applications
- Sample applications that demonstrate common display workflows
- Qt platform plugin integration for Qt-based applications
- Supporting configuration and packaging metadata for Yocto builds

!!! warning

	The Yocto meta-layer for DisplayLink Direct is not available yet.
	Recipes, integration files, and build support for Yocto-based systems will be added in a future release.
