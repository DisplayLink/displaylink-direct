# Core Libraries

This directory contains the platform-specific pre-built core libraries used by
DisplayLink Direct.

The core libraries are proprietary and closed source. They are distributed as
GitHub Release Assets and are not included in the source archive. For download
instructions, see the
[Getting Started](https://displaylink.github.io/displaylink-direct/getting-started/)
guide under the **Core Libraries** section.

For installation and usage guidance, see the Getting Started page:

- [Getting Started](https://displaylink.github.io/displaylink-direct/getting-started/)
