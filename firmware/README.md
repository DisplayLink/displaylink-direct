# Firmware Directory

This directory contains DisplayLink device firmware packages (`.spkg` files)
used by DisplayLink Direct during automatic or manual firmware update.

The `.spkg` files are distributed through the GitHub Release Assets for each
DisplayLink Direct release and should be downloaded from there.

For download instructions, see the
[Getting Started](https://displaylink.github.io/displaylink-direct/getting-started/)
guide under the **Firmware** section.

For usage instructions, firmware compatibility notes, and update samples, see
the Getting Started page:

- [Firmware Update](https://displaylink.github.io/displaylink-direct/getting-started/firmware-update/)
