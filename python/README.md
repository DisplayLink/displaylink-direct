# DisplayLink Direct Python Bindings

The Python bindings let you integrate DisplayLink Direct into your
Python applications. Pre-built wheels (`.whl`) for supported Python versions and
architectures are published as [GitHub Release Assets](https://github.com/displaylink/displaylink-direct/releases/).

## Documentation

Full installation and usage instructions for the Python bindings are available
in the documentation:

- Getting Started — Python Bindings:
  <https://displaylink.github.io/displaylink-direct/getting-started/python-bindings/>

The documentation covers prerequisites, installing from a wheel, verifying the
installation, and host setup details such as USB permissions.
