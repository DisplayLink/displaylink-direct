typedef void(* dlsdk_hotplug_callback_fn) (dlsdk_hotplug_event_data *data, void *user_data)

Hotplug callback function type.

You must not register or unregister callbacks from within a callback. Callbacks are invoked on an internal SDK worker thread. Callbacks are serialized and delivered in event order.

Parameters
[in]dataNon-null pointer to a struct containing event data.
[in]user_dataUser data pointer provided at registration.

◆ dlsdk_get_devices()

DLSDK_EXPORT dlsdk_status dlsdk_get_devices ( dlsdk_device_handle *  devices,
unsigned int *  size 
)

Function used to obtain the attached devices.

The caller must allocate enough memory to store the device handles (dlsdk_device_handle) before calling this method. If there are more attached devices than memory allocated, the function will return DLSDK_NOT_ENOUGH_SPACE. If this happens, the user must then allocate memory equal to the value of the returned size before calling this function again.

Parameters
[in,out]devicesA pointer to a contiguous piece of memory big enough to store the number of connected device handles. If NULL is passed, the function will only return the number of connected devices in size parameter.
[in,out]size[in]: the number of device handles that can be stored in the devices parameter. [out]: The number of attached devices.
Returns
DLSDK_NOT_ENOUGH_SPACE if there are more attached devices than allocated memory for storing dlsdk_device_handle.

DLSDK_EXPORT dlsdk_status dlsdk_register_hotplug_callback ( dlsdk_hotplug_callback_fn  cb,
void *  user_data,
dlsdk_hotplug_callback_handle *  outHandle 
)

Register a hotplug callback function.

This function registers a callback to be invoked when a hotplug event occurs and returns a registration handle for later unregistration. Only one callback can be registered, and registering a new callback will overwrite the previous one. The callback will be invoked for all hotplug events from the moment the callback is registered. When a system is destroyed, all hotplug callbacks will be automatically unregistered and their handles invalidated.

Parameters
[in]cbthe function to be invoked when a hotplug event occurs. Must be non-NULL.
[in]user_datauser data to pass to the callback function. Can be NULL if not needed.
[out]outHandleCallback registration handle. Must be non-NULL. On success, receives a non-NULL handle.
Returns
DLSDK_SUCCESS on success, otherwise an error code.

◆ dlsdk_unregister_hotplug_callback()

DLSDK_EXPORT dlsdk_status dlsdk_unregister_hotplug_callback ( dlsdk_hotplug_callback_handle  handle)

Unregisters a hotplug callback.

You must not register or unregister callbacks from within a callback. Callback will not be invoked after this function returns successfully. If the callback is currently running, this function will block until it completes before unregistering and returning.

Parameters
[in]handleThe callback registration handle returned during registration.
Returns
DLSDK_SUCCESS on success, DLSDK_INVALID_HANDLE if handle is unknown or already unregistered, otherwise an error code.

◆ dlsdk_update_firmware()

DLSDK_EXPORT dlsdk_status dlsdk_update_firmware ( dlsdk_device_handle  device,
const char *  firmwarePath 
)

Function used to update the firmware of a device.

Synchronous function used to update the firmware on a specific device. This function will block until the firmware update process is complete, which may take up to 30seconds on the device. This method must be called by the user to update the firmware on a specific device. This is required when the SDK is initialised with null firmware path, and can be used to update the firmware on demand. It is advised to keep the firmware up to date to ensure the best performance and reliability of the device, as well as access to the latest features. After a successful firmware update, the device handle is still valid, but all display handles obtained from that device are invalid and must be obtained again by calling dlsdk_device_get_displays() to reflect the new firmware state.

Parameters
[in]deviceThe device handle. Must be valid and non-NULL.
[in]firmwarePathThe path to the firmware directory provided by DisplayLink. Must be valid and non-NULL.
Returns
DLSDK_SUCCESS on success, otherwise an error code. DLSDK_UNSUCCESSFUL_NO_DEVICE if the device is not found within 15seconds after firmware update
