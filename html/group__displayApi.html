◆ dlsdk_display_show()

DLSDK_EXPORT dlsdk_status dlsdk_display_show ( dlsdk_display_handle  display,
dlsdk_pixel_format  format,
const void *  pixels,
unsigned int  stride 
)

Function to present the contents of a pixel buffer on the display.

This is a non-blocking call and will return before the pixels are displayed. If the user wishes notification of when the pixels have been displayed, they should call dlsdk_display_wait_on_show()

See also
DisplayHandle::show()
Parameters
[in]displayDisplay handle. Must be valid and non-NULL
[in]formatThe pixel format contained in the pixel buffer
[in]pixelsThe buffer containing the pixels to be displayed
[in]strideNumber of bytes that needed to add to the address of the first pixel of a row in order to go to the address of the first pixel of the next row. If a value of 0 is given then it will be automatically calculated as bytes per pixel * display width
Returns
DLSDK_SUCCESS if the frame was successfully submitted for rendering, or an error code on failure. The caller should check the render and frame transmission status with dlsdk_display_wait_on_show().

◆ dlsdk_display_wait_on_show()

DLSDK_EXPORT dlsdk_status dlsdk_display_wait_on_show ( dlsdk_display_handle  display)

Function used to block for notification that pixels have been displayed after calling dlsdk_display_show()

Parameters
[in]displayDisplay handle. Must be valid and non-NULL
Returns
DLSDK_SUCCESS when the pixels have been displayed
DLSDK_UNSUCCESSFUL_NO_MONITOR when display is not ready
DLSDK_BUSY when the device aborted a previously submitted frame due to resource constraints. The caller should retry dlsdk_display_show() with the frame to be displayed, which will typically involve more aggressive compression, or proceed with new frame if the previous frame is no longer relevant.
DLSDK_TIMEOUT if waiting for the display to be ready timed out
DLSDK_UNSUCCESSFUL on unknown error
