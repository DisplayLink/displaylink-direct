DLSDK_EXPORT dlsdk_status dlsdk_device_get_displays ( dlsdk_device_handle  device,
dlsdk_display_handle *  displays,
unsigned int *  size 
)

Function used to obtain the attached displays for a given device.

The caller must allocate enough memory to store the display handles (dlsdk_display_handle) before calling this method. If there are more attached displays than memory allocated, the function will return DLSDK_NOT_ENOUGH_SPACE. If this happens, the user must then allocate memory equal to the value of the returned size before calling this function again.

See also
DeviceHandle::getDisplays()
Parameters
[in]deviceDevice handle. Must be valid and non-NULL
[in,out]displaysA pointer to a contiguous piece of memory big enough to store the number of display handles connected to the device. If NULL, the function will only return the number of attached displays in size parameter.
[in,out]size[in]: the number of display handles that can be stored in the displays parameter. [out]: The number of attached displays.
Returns
DLSDK_NOT_ENOUGH_SPACE if there are more attached displays than allocated memory for storing dlsdk_display_handle.

DLSDK_EXPORT dlsdk_dpaux_handle dlsdk_device_get_dpaux ( dlsdk_device_handle  device,
unsigned int  output 
)

Function used to obtain a handle to the DP AUX channel available on a given device.

Some devices may not have a DP AUX channel, in which case this function will return NULL. This function is useful when low-level access to the DP AUX channel is required and display is not enumerated automatically. Otherwise, it is recommended to obtain the DP AUX channel handle via the display object using dlsdk_display_get_dpaux().

Parameters
[in]deviceDevice handle. Must be valid and non-NULL
[in]outputThe output index for which to obtain the DP AUX channel handle
Returns
A handle to the DP AUX channel or NULL if the device does not support it, output is not DP type or it does not exists.
